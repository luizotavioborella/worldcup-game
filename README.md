# ⚽ Dream Cup XI

A football game developed as a group web project, combining programming, design and content creation.

The project was created during a SENAI activity focused on the use of Artificial Intelligence in the development of a complete digital product.

## ✨ Features

- Build your own football team
- Player selection
- Team lineups
- Football matches
- Single-player mode
- Local multiplayer
- Match results and score system
